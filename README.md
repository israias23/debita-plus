# 📖 Descrição

O **Debita+** é uma aplicação web desenvolvida para auxiliar no **controle e organização de dívidas pessoais**, permitindo que usuários registrem e acompanhem compromissos financeiros de forma simples e acessível.

A aplicação foi construída utilizando tecnologias fundamentais da web e estruturada para funcionar também como **Progressive Web App (PWA)**, possibilitando instalação em dispositivos móveis ou desktops e funcionamento semelhante a um aplicativo nativo.

O sistema foi projetado para demonstrar como aplicações web podem ser utilizadas para criar ferramentas práticas de **gestão financeira pessoal**, com foco em simplicidade, acessibilidade e organização de informações financeiras.

# 📱 Progressive Web App (PWA)

O **Debita+** foi desenvolvido como um **PWA**, permitindo:

* instalação do aplicativo no dispositivo
* acesso rápido pela tela inicial
* experiência semelhante a um aplicativo nativo
* funcionamento direto pelo navegador

PWAs são amplamente utilizados para transformar aplicações web em experiências mais próximas de aplicativos mobile.

---

# 🧠 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento web:

* **HTML5** — estrutura da interface
* **CSS3** — estilização e layout da aplicação
* **JavaScript (ES6)** — lógica da aplicação
* **Service Worker** — suporte ao funcionamento como PWA
* **Manifest Web App** — configuração de instalação do aplicativo

Essas tecnologias permitem que a aplicação funcione **diretamente no navegador**, sem necessidade de frameworks ou dependências externas.
